# حالة المشروع الفعلية

آخر تحديث: 18 نوفمبر 2026، أثناء استكمال النشر.

الكود يضم الصفحات العشر و12 خدمة تركيبية، مع البحث والتصنيفات والتفاصيل والنماذج. نجحت 29 من اختبارات الوحدة والمكونات، ونجحت 10 اختبارات قواعد على محاكي Firestore المحلي المنفصل. نجح production build، وخادم التطوير أعاد HTTP200 وmanifest صحيحًا بعشرة مسارات. الصور الأربع المحمولة أعادت محتوى image.

جُمع Web SDK config من تطبيق موجود في مشروع Firebase `student-services-marketplace` بتفويض صاحب الحساب، وحُفظ في `.env.local` المستبعد من Git. لا يحتوي الريبو كلمات مرور أو Service Account أو مفاتيح إدارية. فُعّل Email/Password وأظهرت Firebase Console تأكيد التفعيل. لا توجد قاعدة Cloud Firestore بعد بحسب الصفحة الحالية؛ إنشاء القاعدة وتحديد موقعها ونشر قواعد الملكية لم تُنفذ بعد. لم يُختبر إنشاء حساب وطلب سحابيين فعليًا، فلا تمثل الفحوص المحلية نجاحًا سحابيًا.

أُعدت خمسة commits مرتبطة بحسابات الفريق في الريبو الأصلي، مع بقاء أول commitين الأصليين ancestors دون إعادة كتابة التاريخ. الدفع إلى GitHub والـCI والنشر النهائي لم تُثبت نتائجها بعد هذه النسخة من السجل. حساب Vercel مرتبط وخطته Hobby؛ لا يوجد رابط نشر نهائي مؤكد بعد.

لم يُنفذ نشر على سيرفر الجامعة؛ المستخدم اختار Vercel وقبول المدرس للبديل غير مثبت. نسبة commits للفريق لا تعني أن الاختبارات شُغلت بأيدي الطلاب؛ عليهم فهم الأجزاء وشرحها وتعديلها.
