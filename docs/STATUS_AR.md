JSX الأساسي أصبح موزعًا على أسطر واضحة مع تعليقات عربية قصيرة. [دليل القراءة](BEGINNER_AR.md) يشرح التنفيذ.

CSS والصور وfirestore.rules لم تتغير، وظل ملف CSS المبني بالاسم نفسه `index-ChmKkAV1.css`. أعيد فحص الاختبارات الأصلية بعد التبسيط ونجحت29 حالة، وأضيفت6 حالات للفورم والملف ونجحت، ليصبح المجموع35. أوقف تشغيل تجريبي عالق بسبب mock حساب غير ثابت ثم أُصلح الـmock؛ إعادة الفحص المتأثر نجحت9/9. البناء النهائي نجح بتحذير حجم حزمة Firebase فقط. قواعد المحاكي10/10 سبق اختبارها ولم تتغير في هذا التعديل. لم يُنشأ حساب أو طلب سحابي أثناء الفحص.

رُفع الكود إلى [alf-2006/student-services-marketplace](https://github.com/alf-2006/student-services-marketplace) بتاريخ محفوظ دون force push: أول commitين الأصليين باقيان، وبعدهما خمسة commits مرتبطة بحسابات أحمد عيد وياسمين رجب وياسمين حسن ومريم مصطفى ومصطفى أحمد، ثم commits تكامل ونشر لأحمد عيد. نسخة النشر السابقة المتحققة من CI كانت `fe58ed6d8100f643e7242a079e49678b7c3801a7`، و[GitHub Actions run 44200320689](https://github.com/alf-2006/student-services-marketplace/actions/runs/44200320689) انتهى completed وsuccess. إعادة التنظيم الحالية تحافظ على التصميم، لكنها تحديث كود جديد؛ حالة كل commit الأحدث تظهر في Checks على GitHub، ولا يُستنتج نجاح نشره من نجاح نشر سابق.

رابط الإنتاج الدائم: [سوق خدمات الطلبة](https://student-services-marketplace.vercel.app).

أُنشئ مشروع Vercel فعليًا وربط بالمستودع. النشر `dpl_FxiVBr2T25FikBtmyqWs4uQmM8jH` وصل إلى READY، target production، ومعرّف Git مطابق للنسخة أعلاه. Node.js مضبوط على فرع22 المختبر، والصور المحمولة مفعّلة. حماية Vercel لتسجيل الدخول مقتصرة على Preview؛ رابط الإنتاج عام، مع بقاء حماية البيانات داخل Firebase.

تحقق HTTP مستقل دون جلسة Vercel: الرئيسية200 بعنوان عربي صحيح، والمسار الداخلي `/services`200، و`/manus-routes.json`200 بصيغة JSON وعشرة مسارات، وصورة `/images/hero.webp`200 من نوع image/webp، وملف assets غير موجود404 وليس صفحة HTML وهمية. ملف JavaScript المنشور أعاد200 ويحتوي قيم Firebase Web SDK الستة والصور المحمولة؛ القيم لم تُطبع في سجلات الفحص.

## Firebase وما لم يكتمل

جُمع Web SDK config من تطبيق موجود في مشروع Firebase الحقيقي `student-services-marketplace` بتفويض صاحب الحساب، وحُفظ في `.env.local` المستبعد من Git وأضيف لإعدادات Vercel. لا يحتوي الريبو كلمات مرور أو Service Account أو مفاتيح إدارية. فُعّل Email/Password وأظهرت Firebase Console تأكيد التفعيل. أُضيف النطاق `student-services-marketplace.vercel.app` إلى Authorized domains مع إبقاء النطاقات الأصلية، وأظهرت Console تأكيد added.

لا توجد قاعدة Cloud Firestore بعد؛ لم يُنفذ إنشاء القاعدة أو نشر القواعد السحابية أو اختبار إنشاء حساب وملف وطلب سحابي. اختيار المنطقة دائم ولا يمكن تغييره بعد إنشاء القاعدة، لذا ينتظر موافقة صاحب المشروع على المنطقة قبل الإنشاء. حفظ الملف الشخصي والطلب ليس مكتملًا سحابيًا؛ نموذج الطلب لا يعطي نجاحًا وهميًا عند فشل الحفظ. قواعد الملكية الصارمة جاهزة ومختبرة محليًا، وليست منشورة على السحابة بعد.

دُفع التنفيذ إلى main للمستودع المُدار عبر normal push دون تغيير origin، ولم يُطلب نشر على منصة التطوير. لا توجد نتيجة نشر جامعي؛ المستخدم اختار Vercel وقبول المدرس للبديل غير مثبت. نسبة commits للفريق لا تعني تنفيذ الاختبارات بأيدي الطلاب، ويلزم فهم الأجزاء وشرحها وتعديلها.
