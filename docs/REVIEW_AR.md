# مراجعة التكامل — مصطفى أحمد

وُزع المشروع إلى خمس وحدات مستقلة مرتبطة بالفريق: الحساب والملف، الواجهة المشتركة، الكتالوج والبحث، الطلبات والقواعد، ثم مراجعة الربط ومطابقة التكليف. المراجعة الخامسة كانت للقراءة فقط؛ نُفذت الإصلاحات بعدها في مرحلة التكامل. هذه نسبة لتوزيع العمل وليست شهادة أن كل طالب كتب الكود أو شغّل الاختبارات بنفسه.

## الملاحظات التي عولجت

لم تكن قيم SearchBar وServiceFilters تتبع تغير URL والرجوع والتقدم، واحتوت قائمة البحث تصنيفات غير موجودة. أصبحت القيم تتزامن مع المسار، والخيارات مشتقة من التصنيفات الفعلية. اختبارات regression تغطي الرجوع والتقدم وتغيير التصنيف والترتيب.

كانت خدمة الملف الشخصي تعيد كتابة تاريخ الإنشاء في كل تحديث. انفصل إنشاء الملف عن تعديل حقوله؛ البريد والهوية من جلسة Auth، والتعديل يرسل الاسم والكلية فقط. تتحقق قواعد Firestore من الحقول والأنواع والأطوال والبريد المطابق للحساب وserverTimestamp عند الإنشاء، وتمنع تغيير uid والبريد والتاريخ أو الحذف.

كان تأخر استجابة طلبات حساب سابق قد يستبدل بيانات الحساب الجديد. ارتبطت النتائج بهوية المالك ورقم جيل التحميل، مع إخفاء البيانات القديمة في render نفسه وتجاهل الاستجابات بعد تبديل المستخدم أو الخروج أو إزالة المكون. اختبارات باستجابات معكوسة تغطي العيب تحديدًا.

أزيل main المتداخل، وأصبح للصفحة الرئيسية والصفحات الداخلية وحالة 404 landmark واحد. صُحح اختبار منع قراءة طلب مالك آخر ليستخدم getDoc بدل setDoc، وأضيف اختبار الاستعلام المقيد بالمالك ومنع الحذف والتعديل وإعادة تفعيل طلب ملغى.

## النتائج المثبتة

بتاريخ 17 نوفمبر 2026 UTC، نجح `pnpm test`: 29 اختبار وحدة ومكوّن. يتخطى هذا الأمر 10 اختبارات محاكي بسبب بوابتها؛ نجحت العشرة فعليًا عند تنفيذ `pnpm test:rules` على Firestore Emulator المحلي وJava21، ثم أُغلق المحاكي بنجاح. رسائل PERMISSION_DENIED في اختبارات الرفض متوقعة ولا تعني فشل المجموعة.

نجح `pnpm build` وأنتج `dist`، مع تحذير حجم حزمة تضم Firebase وليس خطأ بناء. لا تمثل هذه النتائج شهادة WCAG أو مراجعة بصرية شاملة أو اتصالًا سحابيًا. [الحالة الفعلية](STATUS_AR.md) تسجل Firebase وVercel والفحوص اللاحقة بشكل منفصل.

CI مهيأ لإعادة تشغيل الوحدة والمحاكي والبناء عند push وpull request. لا تُعتبر نتيجة CI ناجحة قبل ظهور نتيجة GitHub Actions الفعلية. الاختبارات المذكورة نفذتها بيئة العمل الآلية، وليست إثباتًا لتنفيذ الطلاب بأيديهم.

## نقاط المناقشة

أحمد عيد يشرح onAuthStateChanged والفصل بين Auth وFirestore وحالة نجاح الحساب مع فشل الملف. ياسمين رجب تشرح RTL والتنقل وlabels وتركيب المكونات. ياسمين حسن تشرح تطبيع البحث العربي وquery parameters وحالة النتائج الفارغة. مريم مصطفى تشرح validation والفرق بين فحص المتصفح والقواعد والحفظ والإلغاء. مصطفى أحمد يتتبع الرحلة من بطاقة الخدمة إلى الطلب المحفوظ ويشرح اختبار سباق الحسابات والفرق بين build وdeploy.
