# دليل وحدة الخدمات

## النطاق

تملك هذه الوحدة بيانات الخدمات والطلاب التجريبية، التصنيفات، البحث والترشيح، وصفحات الخدمات والتصنيفات والنتائج والتفاصيل، بالإضافة إلى تنسيقاتها واختبارات منطقها. كل البيانات المعروضة اصطناعية للتوضيح وليست ملفات تعريف أو عروضًا حقيقية.

## البيانات والعقود

- `src/data/services.js` يصدّر `services` و`students` و`getServiceById` و`getStudentById`.
- توجد 12 خدمة على الأقل موزعة بين `tutoring` و`design` و`printing`.
- توجد خمسة ملفات طلاب تجريبية بالضبط، ويبدأ ترتيبها بالمعرّف `student-ahmed`. كل بريد ينتهي بـ`.example`.
- الصور تمر عبر `imageKey` وتُحل من `src/data/imageAssets.js`، ولا تُستخدم كصور أشخاص حقيقيين.

## البحث والتنقل

`filterServices` دالة نقية تقبل `query` و`category` و`sort`. البحث يطابق عنوان الخدمة أو اسم التصنيف العربي، ويتجاهل الحركات والتطويل ويوحّد أشكال الألف. قيم الترتيب هي `recommended` و`price-asc` و`price-desc`. صفحات الخدمات والنتائج تحفظ `q` و`category` عند الانتقال إلى التفاصيل أو العودة.

صفحة التصنيفات تعرض محتوى مستقلًا وتربط كل تصنيف بنتائج مفلترة. صفحة النتائج تعرض حالة عدم وجود نتائج مع رابط لمسح البحث والفلاتر. صفحة التفاصيل لا تستبدل المعرّف المجهول بخدمة أخرى؛ بل تعرض حالة عدم العثور صريحة، وتعرض وصف الخدمة والسعر والوحدة ومدة التسليم ومقدم الخدمة ورابط ملفه وزر الطلب بالمعرّف نفسه.

## ملاحظات المنتج

الأسعار منسقة عبر `Intl.NumberFormat` للغة `ar-EG` وبعملة EGP. بيانات التواصل في التفاصيل موسومة بوضوح بأنها تجريبية، ولا توجد تقييمات أو شهادات مستخدمين مختلقة. نموذج الطلب والحفظ الفعلي في Firebase تملكه وحدة الطلبات؛ هذه الوحدة لا تنشئ جلسات دخول ولا تحفظ كلمات مرور.

## الاختبار

الاختبار المملوك هو `tests/services.test.js` ويغطي البحث بالنص والتصنيف، التطبيع العربي، ترتيب الأسعار، وسلوك المعرّفات غير المعروفة. التشغيل المقصود:

```bash
pnpm test --run tests/services.test.js
```

يجب تشغيله بعد اكتمال تثبيت الاعتمادات، ولا يتصل الاختبار بمتصفح أو Firebase أو بيانات سحابية.
